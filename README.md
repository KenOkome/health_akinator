# 🔮 ヘルス・アキネーター (Health Akinator)

あなたの体の声を見通すAI診断アシスタント。  
気になる症状（頭痛、腹痛、だるさなど）を入力すると、アキネーター風の魔神が1問ずつ質問を投げかけ、可能性のある一般的な病気や体調不良の原因を段階的に絞り込んで推測します。

---

## 🌟 主な特徴

- **Gemini 3.5 AIリアルタイム対話**:
  - Google Gemini 3.5 Flash-Lite により、入力された主訴に合わせて質問を1問ずつ動的に生成。
  - 自然な対話形式で症状の核心に迫ります。
- **内蔵推論エンジン（スマート適応モード）**:
  - API未接続時でも、頭痛・腹痛・倦怠感などのナレッジベースによりオフラインでもスムーズに推論可能。
- **確率グラフ ＆ 具体的アクション提案**:
  - 推測疾患の確率分布（合計100%）
  - おすすめの受診科
  - 市販薬の目安
  - 今すぐできる応急ケア ＆ おすすめ食事・予防法
- **緊急アラート（レッドフラッグ検知）**:
  - 突然の激痛や意識障害、呼吸困難などを検知した場合、速やかに救急車（119番）の手配を促します。
